# Vibe Coding Figure 1 — Figma import

This folder recreates **FIGURE 1** (three-column vibe coding diagram) for Figma/FigJam.

## Option A: Import SVG (closest to the paper figure)

1. Open Figma Design or FigJam.
2. **File → Import** (or drag and drop) `vibe-coding-figure-1.svg`.
3. Ungroup if you need to edit individual bubbles or mockups.

## Option B: FigJam Mermaid diagram (editable flow)

If you use **Cursor with Figma MCP** connected (Desktop):

1. Run the `generate_diagram` tool with:
   - **name:** `Vibe Coding Figure 1 — Process Flow`
   - **mermaidSyntax:** contents of `vibe-coding-figure-1.mmd`

This produces a structured three-column flowchart (not pixel-identical to the paper, but editable in FigJam).
